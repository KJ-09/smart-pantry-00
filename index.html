앱 매뉴얼 & 사용 설명서

📌 1. 프로그램 소개

Smart Pantry는 식재료의 유통기한 관리와 스마트 장보기 체크리스트를 한곳에서 관리하는 PWA 기반 웹 앱입니다.

추천 대상: 유통기한이 지나 음식을 자주 버리는 분, 장볼 때 중복 구매를 방지하고 싶은 1인 가구 및 주부.

📱 2. 접속 및 앱(PWA) 설치 방법

  • 앱 설치 버튼: 상단 헤더의 황색 [앱 설치] 버튼을 누르면 스마트폰 및 PC에 앱으로 즉시 설치됩니다.
  • Android (Chrome): 상단 설치 버튼을 누르거나 메뉴(⋮) ➔ '홈 화면에 추가' 선택
  • iOS (Safari): Safari 하단 공유 버튼 클릭 ➔ '홈 화면에 추가' 선택

🖥️ 3. 화면 및 버튼 안내

  • 상단 헤더: 타이틀, [앱 설치] 버튼 및 [도움말] 버튼이 위치합니다.
  • 하단 네비게이션: 재고 관리 탭과 장보기 리스트 탭을 전환합니다.
  • [+ 품목/항목 추가] 버튼: 새로운 재고 또는 장볼 식재료 등록 모달창을 엽니다.
  • 입력칸: 품목명, 카테고리, 수량, 유통기한(재고 전용) 입력 필드.
  • D-Day 배지: 유통기한 잔여일을 자동 계산해 표시 (녹색: 안전, 빨간색: 3일 이하 임박/만료).

⚙️ 4. 기능별 단계별 사용 방법

기능 1: 냉장고 재고 등록 & 유통기한 관리

  1. 하단 '재고 관리' 탭 선택 후 [+ 품목 추가] 클릭
  2. 품목명, 카테고리, 수량, 유통기한을 입력하고 [저장] 클릭
  3. 목록에서 D-Day 배지로 유통기한 임박(D-3 이하) 품목을 파악합니다.

기능 2: 장보기 체크리스트 작성

  1. 하단 '장보기 리스트' 탭 선택 후 [+ 항목 추가] 클릭
  2. 구매할 품목명, 카테고리, 필요 수량 입력 후 [저장] 클릭
  3. 마트에서 장볼 때 구매한 품목의 좌측 체크박스를 선택합니다.

기능 3: 장보기 완료 후 재고로 자동 이관

  1. 장보기 리스트에서 항목 체크시 활성화되는 [구매 완료] 버튼 클릭
  2. 해당 항목이 장보기 리스트에서 삭제되고 '재고 관리' 탭으로 즉시 이동합니다.
  3. 재고 관리 탭에서 유통기한을 추가로 편집해 보관할 수 있습니다.

⚠️ 5. 주의사항 & 자주 묻는 질문 (FAQ)

Q. 인터넷이 안 되어도 사용할 수 있나요?

네, PWA 기술이 적용되어 오프라인 환경에서도 완벽하게 동작합니다.

Q. 저장한 데이터가 사라질 위험이 있나요?

데이터는 기기의 웹 브라우저(LocalStorage)에 안전하게 저장됩니다. 단, 브라우저 방문 기록 및 쿠키/캐시 삭제 시 초기화될 수 있습니다.
